## Modelo de Conversão de Dados ETL

 Usa apenas um banco de dados puxando de uma api e converte usando um arquivo CSV para listar e limitar os usuários.
 Então a chave é ativada e mandada para a API que adicona as frases perosnalizadas aos usuários.

 ### Tecnologias Usadas

 * Linguagem > Python
 * I.A generativa > ChatGPT
 * Listagem de usuários > Libreoffice / LibreoficeCalc (Arquivo CSV)
